Follow the Kubernetes (Helm) script in docs/DEPLOYMENT.md: it drains,
initializes and starts the workloads in order and stops at the first failure.

After the first start, connect the model provider once; the login is stored on
the Hermes volume:

  kubectl -n {{ .Release.Namespace }} exec -it deployment/hermes-review -- hermes model
  kubectl -n {{ .Release.Namespace }} exec deployment/hermes-review -- /opt/review-agent-bootstrap/install.sh
  kubectl -n {{ .Release.Namespace }} rollout restart deployment/hermes-review
