# Learning reports

Generated learning-candidate reports can be written here when they are useful
to review as versioned artifacts. They are advisory, may contain sensitive
human-entered reasons, and must be scrubbed before commit.

This directory also holds scrubbed, bounded historical replay receipts. A
receipt records the exact source and policy identities, isolation conditions,
and structured reviewer output. It is evidence for human promotion, not a new
runtime policy source or an automatic model gate.
